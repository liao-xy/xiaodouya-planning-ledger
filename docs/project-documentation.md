# 小兜芽 项目说明文档

> 让每一笔钱都有去处。

小兜芽是一款面向所有人的规划型记账微信小程序。它不把记账当作事后流水，而是把“当前真实余额”变成可以被看懂、被分配、被持续执行的生活计划。

## 一、我们想解决什么问题

普通记账工具通常只能回答“我已经花了多少钱”，却很难回答三个真正影响决策的问题：

1. 我现在的钱里，有多少已经有用途？
2. 除去已经安排的钱，我还能自由花多少？
3. 我的消费习惯和我想要的生活是否一致？

小兜芽以“先规划，再记账”为核心。用户先记录真实收入，再把余额分配至日常生活、旅行、学习等资金计划；此后的每笔支出会影响对应计划，而不是孤立地出现在流水中。

## 二、核心创新：钱的去处，而不只是预算数字

### 真实余额约束

资金计划不是独立于钱包的愿望清单。小兜芽使用以下规则：

- 当前钱包 = 全部历史收入 − 全部历史支出；
- 已分配 = 所有计划尚未使用金额之和；
- 未分配 = 当前钱包 − 已分配；
- 只有未分配金额可以继续创建计划，或记录不归入计划的支出；
- 归入计划的支出不能超过该计划的剩余金额。

这使“预算”与“能不能花”建立真实关系，避免用户设定了很多预算，却忽略钱包实际余额。

### 情绪友好的钱格测试

小兜芽将 8 道轻量问题与用户真实收支、规划和记账习惯综合分析，形成 8 种钱系人格结果。它不以“自律/不自律”给用户贴标签，而是通过更轻松的角色和专属形象帮助用户理解自己的消费节奏，并给出下一步行动建议。

### 依据真实数据的兜兜 AI

兜兜 AI 不直接相信前端传入的统计结果。每次回答前，服务端会为当前登录用户生成数据快照，包含真实账单、消费分类、资金计划、近 6 个月趋势、近期记录和最新钱格测试。AI 只能依据快照回答，并优先提供不超过 3 条带金额、分类、计划或时间依据的可执行建议。

## 三、功能清单

### 1. 收支与账单

- 快速录入收入/支出、分类、金额、备注、日期和归属计划；
- 支持生活费、工资薪酬、红包补贴等收入分类；
- 覆盖餐饮、零食、交通、娱乐休闲、礼物人情、网购、学习、话费、宿舍/家居等细分支出分类；
- 支持按月份、收支类型、分类查询账单，并可编辑、删除和重新归入计划。

### 2. 资金计划与预算提醒

- 创建旅行、学习、日常生活等自定义资金计划；
- 清晰展示计划预算、已用、剩余和截止日期；
- 首页同步显示当前钱包、已分配和未分配金额；
- 对计划余额和未分配资金进行约束与提醒。

### 3. 消费构成与每日节奏

- 月度收入、支出、结余总览；
- 分类消费饼图，快速判断支出集中在哪里；
- 每日花销趋势，帮助识别消费节奏；
- 每日一句，服务端按天缓存并更新鼓励短句。

### 4. 兜兜 AI 与钱格测试

- 右下角兜兜悬浮入口，随时进入对话；
- 多会话历史与上下文记忆；
- 基于真实账本的资金整理和消费分析建议；
- 8 种钱格测试结果，配套独立角色形象、分析和建议；
- AI 解读始终优先读取用户最新一次测试结果。

### 5. 账户与安全

- 微信 OpenID 一键身份登录；
- 所有账单、计划、会话均在服务端按用户身份校验；
- 用户协议、隐私政策、内容安全反馈和账号注销入口；
- 明显涉及诈骗、洗钱、赌博、非法交易等高风险 AI 提问会在模型调用前被拦截；
- 备案号、主办者与联系方式预留在“我的 - 服务与资质”中，可通过生产环境变量配置。

## 四、技术架构

```text
微信小程序 / uni-app + Vue 3
            │ HTTPS REST API
            ▼
Java Spring Boot 3
  ├─ 微信 code 换 OpenID 与令牌认证
  ├─ 账单、计划、统计和钱格测试规则
  ├─ 用户数据隔离与内容安全拦截
  └─ 兜兜 AI 数据快照构造
            │
            ├─ MySQL：用户、账单、计划、会话、测试结果
            └─ 阿里云百炼：Qwen3.8-Flash
```

| 模块 | 技术 |
| --- | --- |
| 前端 | uni-app、Vue 3、微信小程序 API |
| 后端 | Java 21、Spring Boot 3、Spring Data JPA |
| 数据库 | MySQL 8；H2 用于本地演示 |
| AI | 阿里云百炼兼容接口、Qwen3.8-Flash |
| 身份 | 微信 `uni.login` + 服务端 OpenID 交换 |

## 五、数据与 AI 处理原则

1. AI 密钥只存在于服务端环境变量，前端不保存密钥。
2. 账单、计划和会话按当前微信 OpenID 对应的用户 ID 做服务端校验，用户不能通过普通接口访问其他用户数据。
3. AI 建议仅用于个人财务整理和参考，不构成投资、借贷、税务或法律意见。
4. 用户可以编辑/删除账单和计划，并在“服务与资质”中注销账户；依法需要留存的安全处置记录除外。
5. 钱格测试的 8 张形象为用户使用 Gemini Nano Banana 生成的视觉资产；产品内对话模型使用阿里云百炼 Qwen3.8-Flash。

## 六、本地运行方式

### 后端

```powershell
cd server
mvn spring-boot:run
```

使用 MySQL 时，配置以下环境变量后启动：

```powershell
$env:SPRING_PROFILES_ACTIVE = "mysql"
$env:MYSQL_URL = "jdbc:mysql://127.0.0.1:3306/guihua?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai"
$env:MYSQL_USERNAME = "你的数据库账号"
$env:MYSQL_PASSWORD = "你的数据库密码"
$env:DASHSCOPE_API_KEY = "你的阿里云百炼 API Key"
```

### 小程序前端

1. 用 HBuilderX 导入 `mobile` 目录；
2. 在 `mobile/src/manifest.json` 填写小程序 AppID；
3. 在微信开发者工具运行；
4. 本地开发时，`mobile/src/config.js` 使用本机后端地址；真机或正式环境需替换为配置在微信后台的 HTTPS 合法域名。

## 七、演示建议

建议按以下顺序体验：登录 → 记录收入 → 新建资金计划 → 记录归入计划的支出 → 查看首页未分配金额和消费饼图 → 向兜兜 AI 提问 → 完成钱格测试并查看 AI 解读。

## 八、项目价值

小兜芽希望把“少花钱”的焦虑，转化为“把钱留给真正重要的生活”的确定感。它的目标不是限制用户消费，而是让用户在日常、体验和长期目标之间，做出更看得见的选择。
