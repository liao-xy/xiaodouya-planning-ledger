# 小兜芽「钱灵宇宙」结果图提示词 v2

这套图的核心不是“钱包吉祥物站在一堆钱罐子旁”，而是像奶系人格测试一样：**每个结果都有独立的轮廓、姿势和物种感，一眼能认出是谁。**

将“小兜芽原始钱包小吉祥物”作为品牌 DNA 参考：薄荷青绿色、圆润软陶质感、叶芽、金色硬币、友善大眼睛。**不要保留原始的普通钱包身体**；把它重新演化成一只独特的「钱灵」。

## 全部图片的共同规则

- 1:1，单个全身主角居中，占画面 70%–80%。像参考图的白色圆角展示卡中的玩偶，而不是故事插画。
- 极简奶系 3D 软陶公仔；背景为象牙白或极浅的薄荷青，只有柔和地面阴影。
- 每张只允许 **一个** 标志性物件，且必须融入身体或动作；禁止桌面、账本、钱罐、散落硬币、复杂场景。
- 角色名和文案由小程序渲染：`no text, no Chinese characters, no letters, no logo, no watermark`。
- 负面提示词统一追加：`do not use the original rectangular wallet body, do not add jars, piles of coins, calculator, desk, charts, background objects, or a busy scene`。

## 图片接入约定

每种钱灵的稳定标识就是章节标题中的 `imageKey`。生成后使用 HTTPS 图片链接更新当前结果：

```http
PUT /api/money-personality/image
Authorization: Bearer <当前登录令牌>
Content-Type: application/json

{ "imageUrl": "https://你的图片域名/personality-p-g-r.png" }
```

小程序会优先展示 `imageUrl`；没有链接时显示对应 `imageKey` 的占位。正式发布时，图片域名必须配置为微信小程序合法下载域名。
