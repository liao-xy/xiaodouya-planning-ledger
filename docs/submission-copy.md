# 小兜芽 作品提交材料

## 项目名称

小兜芽｜让每一笔钱都有去处

## 项目介绍

小兜芽是一款面向所有人的“规划型记账”微信小程序。它不只记录花了多少钱，更先帮助用户把当前真实余额分成清晰的钱的去处：日常生活、旅行、学习或自定义计划；只有未分配的钱才能继续规划或自由消费，避免“预算看起来很多，钱包却没钱”的常见误区。

核心功能包括：收支账单增删改查、细分消费分类、月度收支与结余、消费构成饼图、每日支出趋势、资金计划与未分配余额、预算提醒、每日一句，以及基于真实账单数据的兜兜 AI。AI 由服务端生成专属数据快照，结合最近账单、资金计划和最新钱格测试结果，给出不超过三条可执行建议，避免脱离用户实际数据的泛泛回答。

作品还设计了“钱格测试”：将用户的 8 道选择题与真实收支、规划和记账习惯结合，生成 8 种轻松有趣的钱系人格结果和专属形象，让用户用更有情感的方式理解自己的消费节奏。

技术栈：uni-app + Vue 3、Java Spring Boot 3、MySQL、微信 OpenID 登录、阿里云百炼 Qwen3.8-Flash。

## 可运行地址

当前作品以微信小程序形态运行。请在微信开发者工具导入 `mobile` 目录，并启动 `server` 后端后体验；若表单必须填写公开地址，可填写已部署的 HTTPS 演示地址。没有部署地址时留空，并以演示视频和代码仓库供评审体验。

## 演示视频说明

建议录制 2 分 30 秒至 3 分钟视频并上传至可公开访问的平台。视频应覆盖：

1. 登录页与微信身份登录；
2. 新增一笔收入、为余额创建资金计划、记录一笔归入计划的支出；
3. 首页“当前余额、已分配、未分配”的变化；
4. 消费构成饼图与账单筛选、修改或删除；
5. 兜兜 AI 依据真实账单回答；
6. 钱格测试结果和对应专属形象。

## AI 使用声明

本作品在产品功能和研发环节均使用了 AI：

1. 产品内“兜兜 AI”通过阿里云百炼兼容接口调用 Qwen3.8-Flash。服务端根据当前登录用户的真实账单、资金计划、消费分类、近期趋势、对话上下文与最新钱格测试结果生成数据快照，再由模型给出不超过三条个人财务整理建议。AI 不直接执行记账、资金划转或投资决策；密钥仅保存在后端环境变量中。
2. 钱格测试的 8 张结果形象由用户使用 Gemini Nano Banana 生成，并作为结果页的视觉资产使用。
3. 研发过程中使用 AI 编程助手辅助界面原型、文案和代码实现；核心业务规则、数据隔离、接口结构和最终集成由开发者确认与测试。

## 评审体验提示

- 登录需要配置微信小程序 AppID/AppSecret；本地调试可使用已配置的测试小程序。
- AI 需要在后端设置 `DASHSCOPE_API_KEY` 或 `BAILIAN_API_KEY`；未配置时会使用可解释的本地兜底回答。
- MySQL profile 启用后，账单、计划、会话和测试结果将持久化保存。
